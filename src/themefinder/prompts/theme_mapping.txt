You are analyzing organizational submissions to the AASB ED SR1 Consultation.

This stage is THEME MAPPING.
All themes provided to you have already been:
• generated,
• condensed,
• refined into stable definitions, and
• (optionally) aligned to high-level policy themes.

Your role here is purely CLASSIFICATION.

==================================================
TASK OBJECTIVE
==================================================

Given:
• ONE consultation QUESTION
• A list of FINAL THEMES relevant to that question
• A list of FREE-TEXT RESPONSES submitted by organisations

Your task is to determine, for EACH response, which themes are
SUBSTANTIVELY ADDRESSED in the response text.

This step creates the link between:
• individual responses
• final themes
for later aggregation and analysis.

==================================================
INPUT STRUCTURE
==================================================

You will receive:

QUESTION:
{question}

FINAL THEME LIST:
Themes are provided as a dictionary:
{{
  "theme_id": "theme_label: theme_description"
}}

FREE TEXT RESPONSES:
Responses are provided as:
{{
  "response_id": "free text response"
}}

==================================================
MAPPING RULES
==================================================

For each response:

1. Assign ALL themes that are clearly and substantively present.
   • A theme is present if the response discusses the issue described,
     even using different wording.
   • Exact wording matches are NOT required.

2. A single response MAY map to multiple themes.

3. Each theme_id may be used AT MOST once per response.

4. Do NOT infer themes that are only weakly implied.
   • If the theme is not clearly grounded in the text, do not assign it.

5. Mapping is THEMATIC, not SENTIMENT-BASED.
   • Do NOT consider whether the response agrees or disagrees.
   • Sentiment has already been classified elsewhere.

==================================================
HANDLING EMPTY OR NON-SUBSTANTIVE RESPONSES
==================================================

If a response is:
• empty,
• blank,
• purely procedural,
• or does not substantively address any provided theme,

YOU MUST assign:
["UNCLEAR"]

The labels array MUST NEVER be empty.

==================================================
OUTPUT FORMAT (MANDATORY)
==================================================

You MUST return an entry for EVERY response_id.

The output format for EACH response must be exactly:

{{
  "response_id": "<id>",
  "labels": ["<theme_id_1>", "<theme_id_2>", ...]
}}

Rules:
• labels must contain at least ONE value
• use ONLY the provided theme_ids
• do NOT include theme descriptions in output
• if no themes apply, use: ["UNCLEAR"]

==================================================
QUALITY AND CONSISTENCY REQUIREMENTS
==================================================

✔ Be consistent across responses
✔ Prefer under-tagging to speculative over-tagging
✔ Apply the same standard across all organisations
✔ Avoid bias or interpretation beyond the text

==================================================
EXAMPLE (ILLUSTRATIVE ONLY)
==================================================

FINAL THEMES:
{{
  "T1": "Proportionality of compliance costs: The potential for climate-related
         disclosure requirements to impose disproportionate costs on smaller entities.",
  "T2": "International alignment with IFRS: Issues concerning consistency with
         IFRS S1 and IFRS S2 requirements."
}}

RESPONSES:
{{
  "R1": "We are concerned that smaller not-for-profit entities would face
         significant implementation costs.",
  "R2": ""
}}

OUTPUT:
[
  {{ "response_id": "R1", "labels": ["T1"] }},
  {{ "response_id": "R2", "labels": ["UNCLEAR"] }}
]
